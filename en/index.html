Full-stack · Android + API

CuentasClaras

Shared-expenses app: groups, flexible splits, balances and settlement with the minimum number of transfers.

  • Offline-first Android client: optimistic writes, an outbox table and a SyncWorker with idempotent retries.
  • Spring Boot API with JWT (rotating refresh), Flyway, openapi.yaml as the contract and tests on Testcontainers.
  • Settlement algorithm (exact and heuristic) with money always kept as integers.
  • Kotlin
  • Compose
  • Hilt
  • Room
  • WorkManager
  • Spring Boot
  • PostgreSQL
  • OpenAPI

About
